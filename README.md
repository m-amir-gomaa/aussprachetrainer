## 🗂️ Historical Overview

**Aussprachetrainer** was a German pronunciation trainer with:

- Native Vim keybindings and a keyboard-first workflow
- Regional dialect support (Germany 🇩🇪, Austria 🇦🇹, Switzerland 🇨🇭)
- Offline-first TTS & ASR using `espeak-ng`, `piper-tts`, and `pocketsphinx`
- IPA transcription and pronunciation scoring
- Smart autocomplete powered by frequency analysis
- A dark-mode UI with a Catppuccin-inspired theme
